# trailkit-memo

Notes addon for Guild Wars 2, loaded by [Raidcore Nexus](https://raidcore.gg/Nexus).
Plan: [`docs/plans/addons/trailkit-memo.md`](../../docs/plans/addons/trailkit-memo.md).

> **Status:** phase 1, step 6 — note list (tree) with drag & drop,
> "Move to" and search (M118–M127), rendered note view, own editor with
> preview and chat-link chips, daily/weekly reset notes (kind dropdown,
> countdown, automatic unticking). Trash & undo follow next (memo plan M28).

## Build

From WSL (toolchain is pinned by `rust-toolchain.toml`):

```sh
cargo xtask deploy trailkit-memo            # debug build + copy into the GW2 addons folder
cargo xtask deploy trailkit-memo --release  # release build + copy
```

Build only: `cargo xwin build -p trailkit-memo --target x86_64-pc-windows-msvc`.

## Test

```sh
cargo test -p trailkit-memo   # platform-independent logic (i18n, …) on the host
cargo xtask ui-test           # window snapshots (tests/snapshots/) via the headless ImGui harness
```

## Layout

| Path | Content |
|------|---------|
| `src/lib.rs` | crate root; `all_texts()` collects the texts of the app and every slice for the font atlas |
| `shared/` | crate `trailkit-memo-shared`: note tree, documents, storage worker, localization — what several slices need (ROADMAP R76) |
| `slices/drafts/` | crate `trailkit-memo-drafts`: the draft hint (restore / discard) and its texts |
| `slices/editor/` | crate `trailkit-memo-editor`: edit session, formatting commands, formatting toolbar, title and body inputs, preview |
| `slices/note-list/` | crate `trailkit-memo-note-list`: "New note / New group" header, tree rows, rename, context menu, search hits, drag & drop and its texts |
| `slices/note-view/` | crate `trailkit-memo-note-view`: title (with a trailing widget) and rendered content of the selected note |
| `slices/reset-schedule/` | crate `trailkit-memo-reset-schedule`: reset times, due resets, reset badge, kind dropdown and their texts |
| `slices/search/` | crate `trailkit-memo-search`: search index, results, search field, empty search result and its texts |
| `slices/trash/` | crate `trailkit-memo-trash`: trash column, preview toolbar, group preview, texts of deleting, dialogs and the undo toast |
| `src/main_window.rs` | main window: state, drawing entry point, closing, drafts on unload, due resets (Windows only) |
| `src/main_window/actions.rs` | `WindowAction` and applying it: unsaved-edit guard, then tree, editor and view actions |
| `src/main_window/search.rs` | search cache (index + results), Ctrl+F, Escape in the search field |
| `src/main_window/text_scale.rs` | text size: Ctrl+mouse wheel, Ctrl+0, delayed apply, percentage tooltip |
| `src/main_window/note_list.rs` | note list wiring: search field, menu button, hands search and reset extras to the note-list slice and maps its actions |
| `src/main_window/note_pane.rs` | note pane: toolbar end (`⋯` menu, Edit / Cancel / Save); wires editor, note view, kind dropdown and draft hint |
| `src/main_window/dialogs.rs` | dialog card and window, unsaved-changes and delete questions, storage problems |
| `src/main_window/trash.rs` | deleting (questions, selection after it), trash view actions, Ctrl+Z / Ctrl+Y, hourly purge |
| `src/main_window/trash_pane.rs` | drawing the trash column, the read-only trash preview and the undo toast |
| `src/main_window/layout.rs` | two panes or drawer, empty state |
| `src/main_window/tests.rs` | snapshot and interaction tests of the main window (`tests/trash.rs`: deleting, trash, undo) |
| `src/addon.rs` | Nexus export, load/unload, quick access, render (Windows only) |
| `assets/icons/quick-access.svg` | quick access icon source; the `.png` files next to it are generated by `cargo xtask build-icons` — edit the SVG, then rerun |
| `help/{en,de}.md` | in-game help page source (AGENTS.md rule 6) |
| `package.json` | version placeholder for Changesets (R16) |

## Files

Stored in `addons/trailkit/memo/` inside the Guild Wars 2 folder, through
[`trailkit-storage`](../../crates/trailkit-storage/README.md):

| File | Content |
|------|---------|
| `notes.json` | all notes, groups and the trash |
| `settings.json` | user settings (incl. `text_scale`, M79: text size relative to Nexus' `FontUI`, default 1.125, Ctrl+mouse wheel) |
| `ui_state.json` | selected note, splitter positions, scroll position, note list hidden (M48), preview shown (M60) |
| `backups/` | safety copies (migration copies, unreadable files; later the daily backups) |

## Usage

Click the notes icon in the Nexus quick access bar, or set the keybind
*"Open/close notes"* under Nexus → Options → Keybinds. The window hides during
loading screens, cutscenes and character select and comes back afterwards.
