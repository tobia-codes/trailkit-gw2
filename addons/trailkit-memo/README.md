# trailkit-memo

Notes addon for Guild Wars 2, loaded by [Raidcore Nexus](https://raidcore.gg/Nexus):
a tree of notes and groups, a Markdown editor with preview and chat-link chips,
daily and weekly reset notes, search and a trash with undo.

> **Status:** in development (ROADMAP phase 1), not released yet. Plan and
> every decision: [`docs/plans/addons/trailkit-memo.md`](../../docs/plans/addons/trailkit-memo.md).
> What a user sees: the help page in [`help/en.md`](help/en.md).

## Slices

The addon is an app crate plus one crate per feature (ROADMAP R76). A slice
never depends on another slice; what several need lives in `shared`.

| Crate | What it does |
|-------|--------------|
| [`shared`](shared/README.md) | Note tree, documents and storage worker, settings, undo, localization: what several slices need |
| [`slices/drafts`](slices/drafts/README.md) | The hint to restore or discard a kept draft |
| [`slices/editor`](slices/editor/README.md) | Edit session, formatting commands, toolbar, title and body inputs, preview |
| [`slices/note-list`](slices/note-list/README.md) | The tree: header, rows, rename, context menus, search hits, drag & drop |
| [`slices/note-view`](slices/note-view/README.md) | Title and rendered Markdown of the selected note |
| [`slices/reset-schedule`](slices/reset-schedule/README.md) | Reset times, unticking due tasks, reset badge, kind dropdown |
| [`slices/search`](slices/search/README.md) | Search index and results, search field, empty result |
| [`slices/trash`](slices/trash/README.md) | Trash column, previews of trashed entries, delete dialogs, undo toast |

| Path | Content |
|------|---------|

| `src/main_window/closing.rs` | closing with unsaved changes: close request and approval, drafts kept on unload, the card about notes with drafts |

| `src/main_window/text_scale.rs` | text size: Ctrl+mouse wheel, Ctrl+0, delayed apply, percentage tooltip |
| `src/main_window/note_list.rs` | note list wiring: search field, menu button, hands search and reset extras to the note-list slice and maps its actions |
| `src/main_window/note_pane.rs` | note pane: toolbar end (`⋯` menu, Edit / Cancel / Save); wires editor, note view, kind dropdown and draft hint |
| `src/main_window/dialogs.rs` | dialog card (status line, busy button) and window, unsaved-changes, save-failed and delete questions, storage problems |
| `src/main_window/save_status.rs` | save errors (M180): worker reports, error and success toast, restarting a dead worker; `save_status/editor_commit.rs` the editor's Save that waits for the disk and the save-failed dialog |
| `src/main_window/trash.rs` | deleting (questions, selection after it), trash view actions, Ctrl+Z / Ctrl+Y, hourly purge |
| `src/main_window/trash_pane.rs` | drawing the trash column, the read-only trash preview and the undo toast |
| `src/main_window/layout.rs` | two panes, empty state |
| `src/main_window/window_menu.rs` | the window menu: panel over the full height with a backdrop, its rows |
| `src/main_window/tests.rs` | interaction tests of the main window; `tests/note_list.rs` context menu, dragging, groups; `tests/search.rs` search; `tests/trash.rs` deleting, trash and undo; `tests/save_errors.rs` save errors; `tests/states.rs` one snapshot per state (`tests/states/`, e.g. the minimum width) |
| `src/addon.rs` | Nexus export, load/unload, quick access, render, restart of a dead storage worker (Windows only) |
| `src/addon/storage.rs` | starts the storage worker, hands the loaded notes to the window, restarts a dead worker (Windows only) |
| `src/addon/logging.rs` | Starts and stops the log, forwards texts to `Nexus.log` (Windows only) |
| `assets/icons/quick-access.svg` | quick access icon source; the `.png` files next to it are generated by `cargo xtask build-icons` — edit the SVG, then rerun |
| `help/{en,de}.md` | in-game help page source; updated with every user-visible change (rule 6) |
| `package.json` | version placeholder for Changesets (R16) |

## Files

Stored in `addons/trailkit/memo/` inside the Guild Wars 2 folder, through
[`trailkit-storage`](../../crates/trailkit-storage/README.md):

| File | Content |
|------|---------|
| `notes.json` | all notes, groups and the trash |
| `settings.json` | user settings (incl. `text_scale`, M79: text size relative to Nexus' `FontUI`, default 1.125, Ctrl+mouse wheel) |
| `ui_state.json` | selected note, splitter positions, scroll position, note list hidden (M48), preview shown (M60) |
| `drafts.json` | unsaved edits kept for restoring (M54) |
| `backups/` | safety copies (migration copies, unreadable files; later the daily backups) |

## Build

From WSL (toolchain is pinned by `rust-toolchain.toml`):

```sh
cargo xtask deploy trailkit-memo            # debug build + copy into the GW2 addons folder
cargo xtask deploy trailkit-memo --release  # release build + copy
```

Build only: `cargo xwin build -p trailkit-memo --target x86_64-pc-windows-msvc`.

## Test

```sh
cargo test -p trailkit-memo   # platform-independent logic (i18n, …) on the host
cargo xtask ui-test           # window snapshots (tests/snapshots/) via the headless ImGui harness
```

## Usage

Click the notes icon in the Nexus quick access bar, or set the keybind
*"Open/close notes"* under Nexus → Options → Keybinds. The window hides during
loading screens, cutscenes and character select and comes back afterwards.

## Rules for this addon

- New features become a new slice (or extend one); `src/` only wires slices
  together. A slice may depend on `shared` and `crates/`, never on another
  slice. Blueprint: [`addon-structure.md`](../../.agents/skills/nexus-addon-dev/references/addon-structure.md).
- Nothing on the render thread reads or writes files: all documents go through
  the storage worker in `shared` and [`trailkit-storage`](../../crates/trailkit-storage/README.md).
- Every text exists in English and German; every visible state has a snapshot
  in Dark and Light. General rules: [`CONTRIBUTING.md`](../../CONTRIBUTING.md).
- Logs never contain note content (privacy).
