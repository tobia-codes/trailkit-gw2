## Getting started

memo keeps your notes and checklists in a window inside the game.

### Opening the window

Click the **notes icon** (sheet with pencil) in the Nexus quick access bar, or use the keybind **"Open/close notes"**. The keybind is unbound by default: set it under *Nexus › Options › Keybinds › trailkit-memo*.

The window hides during loading screens, cutscenes and character select and reappears afterwards.

### The window

The window shows the note list on the left and the selected note on the right. Drag the gap between both sides to change their widths (a line appears when you point at it). The note list keeps its width when you resize the window; the note gets the extra room.

The title bar holds these buttons:

- **Menu button**, top left: opens the menu. Click the dimmed area or the button again to close it.
- **?** on the right: opens or closes the help window.
- **Arrow** on the right: collapses the window to its title bar (click it again to expand); **×** closes it.

A highlighted button means that what it switches is shown. Long names are shortened with "…" — hover them to see the full name. In a long note the title stays at the top while you scroll; in a long list the search field and the buttons stay at the top.

### The menu and views

The menu takes you to the different parts of memo:

- **Notes** always brings you back to the regular page: it leaves the trash, closes the search, ends the compact view and shows the note list again.
- **Search notes** shows the search field above the note list, also from the trash. **Trash** shows the trash.
- **Hide note list** gives the note the full width; **Show note list** brings the list back. memo remembers your choice.
- **Compact view** (arrows button, top left of the note): hides the toolbar with *Edit* and the kind box, so the note gets more room. The button behind the title ends it again. You can still choose other notes and tick checkboxes; editing a note (also by double-click) or creating a new one ends the compact view. memo remembers it. Together with a hidden note list only the note is left.
- **Copy text from a note:** drag over the text with the left mouse button to select it, also across lines and paragraphs; Shift+click extends the selection, **Ctrl+A** selects the whole note. **Ctrl+C** or right-click › *Copy* copies it as you see it (a short message at the bottom confirms it): link texts, chips as their chat codes, list items with their `-`, number or `[ ]`. A drag that starts on a link, chip or checkbox selects too; a plain click still opens, copies or ticks. The trash shows its notes the same way, so you can copy from there too. Any click into the window, another note, editing or a new search ends the selection.
- **Moving windows:** drag a window by its title bar; dragging anywhere else never moves it, so you can select text without the window sliding away. This applies to the help window too.
- **Small window:** the window cannot get narrower than the note list and the note need side by side, so the list never disappears by itself; it only gets narrower. Text at a larger size makes this minimum wider.
- **Text size:** hold **Ctrl** and turn the mouse wheel over the window to make all text larger or smaller; **Ctrl+0** goes back to the default. The current size shows next to the mouse in percent; the default size is 100%. memo remembers the size; it builds on the UI font size set in Nexus.

### Help and problems

The **?** in the title bar opens this help window; click it again to close it. **Open help** in memo's tab under *Nexus › Options* opens it too, or brings it to the front. **Escape** closes it.

The window has two tabs: **Help** with these topics, and **Report a problem**, which saves your log as a text file and opens the problem form on GitHub. Below the chosen topic the list shows its sections; click one to jump to it. The **search** above the topics finds every topic and section with your words: the list shows only those, with the number of hits at the end of the row, and a click jumps to the first hit. **Enter** and the arrows go through all hits, as in the note list. **Ctrl+F** finds in the open topic, and **Shift twice** brings memo's window forward with the note search. Until the game restarts, the window opens again on the tab and topic you last looked at. Select text in a topic with the mouse and copy it with **Ctrl+C**, as in a note.

If memo runs into an error, it stops instead of crashing the game: your unsaved text is kept as a draft and this window opens on **Report a problem**. Until you reload memo in the Nexus addon list or restart the game, the keybind and the quick access icon open this window.
